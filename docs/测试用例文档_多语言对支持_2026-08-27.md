## 1. 测试目的

验证以下能力：

- 语言代码可规范化、校验并贯穿核心流水线。
- EN→DE、EN→FR 能正确使用源列、同行目标列和 Key 列。
- 其他常见语言及列表外规范代码具备代码级处理能力。
- 非中文源语不会误用中文分词、姓名规则和中文 Profile 示例。
- 同行目标术语只能从同一行目标文本中沿用。
- 语言对在表头缓存、断点、空术语表和结果中保持隔离。
- CLI 与前端可以表达相同语言对和列映射。
- 原有 ZH→EN、只上传源文件、结果导出和 API 安全能力不回归。

本轮不把真实模型输出质量、德法语言质量、Windows 实机或性能压测列为已通过。

## 4. 前置条件与假设

- 单次任务只有一个源语言和一个目标语言。
- CLI 列索引从 0 开始。
- 同行目标模式要求源文件包含同一行的完整目标文本。
- “代码级支持”表示配置、Prompt、列映射、流水线和结果契约可运行，不代表语言质量已认证。
- 未配置 API Key 时，只执行离线、替身和界面状态测试，不把真实请求记录为通过。
- `DE-MT` 和 `FR-MT` 是机翻列，不作为人工质量金标。
