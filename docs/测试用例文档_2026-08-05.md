## 1. 测试目的与范围

验证本轮修改没有破坏既有流程，并确认以下需求达到可交付状态：

- 网页和 CLI 均支持只提供源文件。
- 网页和 CLI 的关键参数、流水线与输出契约保持一致。
- 主生成、NER、Embedding、表头识别四类 API 均可配置。
- API Key 不写入项目文件、配置、缓存、日志或发布包。
- AI 表头识别在成功、失败、缓存和人工修正场景下行为稳定。
- 页面字段、按钮、侧栏、Logo、响应式布局与结果图表可读。
- 结果导出、标注模板、断点恢复与模型管理功能正常。

本轮不包含 Windows 实机安装、真实 API 完整提取、超大文件、高并发和长时间稳定性压测。

## 3. 前置条件与测试假设

- 源文件首行为列名，至少存在一列可作为中文文本列。
- “只上传源文件”表示参考术语表可省略，不表示主生成服务可完全无 Key 运行正式提取。
- 离线自动化测试不得依赖外部服务或把凭据写入磁盘。
- live 表头识别仅在当前进程提供 `DETECT_API_KEY` 或 `OPENAI_API_KEY` 时执行。
- CLI 列索引从 0 开始；网页端使用列名选择。
- 真实 DeepSeek 表头识别已独立完成 A/B 测试，本轮最终全量回归未重新注入 Key。

## 8. 边界与未验证项

以下项目不能由本轮结果推导为“已通过”：

- Windows 10/11 的 `setup.bat`、`run.bat` 实机安装和启动。
- DeepSeek 以外供应商的逐家兼容认证。
- 超大 Excel、合并单元格、多层表头、损坏文件和异常编码。
- 高并发、长时间运行、断网恢复、供应商持续限流与性能基准。
- 深色模式、Safari/Firefox 专项和辅助技术完整无障碍审计。
- 真实 API 的整条术语抽取、翻译、Embedding 和 NER 联调。
