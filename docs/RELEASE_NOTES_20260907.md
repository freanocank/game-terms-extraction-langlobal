## 使用前必读：仍未修复

1. 候选仍可能漏提、分类不稳或对齐到不完整目标短语。所有结果必须人工审核。
2. 标注工具未识别提取模板的“匹配来源”，且不能保留两个独立的同名异类条目。保留完整原生结果作为复核依据，不把导入后词条数减少直接视为正确去重。
3. 多条历史结果可能触发界面按钮重名错误；必要时直接到任务输出目录查看原生文件，不删除历史数据规避。
4. 秒级任务目录及部分共享状态尚未隔离。当前仅建议单任务使用，不同时新建或恢复多个任务。
5. 取消仅在部分边界检查；最后阶段取消仍可能导出并被标记完成，需核查任务状态和实际产物。
6. 离线重放遗漏工作表名称；导出默认列宽可能截断显示长内容。完整来源验证与视觉验收仍有缺口。
