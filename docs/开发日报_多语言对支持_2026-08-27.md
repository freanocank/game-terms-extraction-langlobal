## 2. 今日开发内容

### 2.1 语言配置层

- 新增 `core/languages.py`，统一管理语言代码、中文名称、UI 标签和表头别名。
- 默认语言对继续为 `zh-Hans → en`。
- UI 内置 26 种常见本地化语言：简繁中文、英语、德语、法语、西班牙语、意大利语、两类葡萄牙语、日语、韩语、俄语、阿拉伯语、土耳其语、波兰语、荷兰语、泰语、越南语、印尼语、乌克兰语、捷克语、匈牙利语、瑞典语、丹麦语、挪威语和芬兰语。
- CLI 支持列表外的规范语言代码，例如 `sr-Latn`。
- 语言代码进入流水线前统一规范化；源语言和目标语言相同时前置拒绝。

### 2.2 核心流水线

- `PipelineOpts` 新增 `source_language`、`target_language`、`src_target_col`、`gl_source_col` 和 `gl_target_col`。
- 保留 `src_en_col`、`gl_cn_col` 和 `gl_en_col` 作为旧调用兼容参数。
- 同行双语文本由固定 `ZH / EN` 改为动态标签，例如：

```text
EN: Training Afternoon | DE: Trainingsnachmittag
EN: Training Afternoon | FR: Après-midi d’entraînement
```

- 结果增加 `source_language` 和 `target_language`，现有 8 列标注模板继续兼容。
- 空值、纯标点和重复源文本继续按既有规则过滤，Key 与保留行保持对应。

### 2.3 Prompt、NER 与 Profile 隔离

- 抽取 JSON 在非默认语言对中统一使用 `term / target_term`，不再把字段语义固定为中英文。
- 翻译 Prompt 显式写入源语言和目标语言。
- 支持以下语言专用 Profile 字段：
  - `core_principle_by_source_language`
  - `extract_examples_by_source_language`
  - `extraction_notes_by_source_language`
  - `fewshot_examples_by_language_pair`
  - `translation_rules_by_language_pair`
- 非默认源语言不会继承旧 Profile 中的中文姓名、中文称谓和中文 Few-Shot 规则；未配置专用规则时使用中性提取原则。
- 非中文源语言不执行 `jieba`、中文姓氏和中文称谓派生过滤。
- 非中文 NER Prompt 要求保持源文拼写，并在同行双语输入中只分析源语言字段。

### 2.4 同行目标术语安全校验

- 同行目标术语必须实际出现在同一行目标文本中，才能标记为“沿用同行译文”。
- 模型只改变大小写时，结果恢复为目标单元格中的原始大小写。
- 模型返回目标文本中不存在的内容时，不再直接照抄；正常模式转入待翻译流程，“仅提取”模式留空并记录说明。
- 只出现在目标文本、未出现在源文本的词，不会被错误归因到源文本或源 Key。
- 术语表优先级保持为：术语表精确命中 > 同行目标译文 > AI 翻译。

### 2.5 Excel 表头与术语表

- 表头识别增加语言对参数和按语言对隔离的缓存上下文。
- 对常见语言代码、语言名称及 `-MT`、版本后缀提供确定性规则识别。
- `EN-v2 / DE-MT / FR-MT / ID` 可在无表头识别 API 的情况下直接映射。
- 空参考术语表按当前语言对生成动态表头，例如 `英语术语 / 法语译文`。
- Embedding 数据库按源语言隔离；断点目录和提取响应缓存按完整语言对隔离。

### 2.6 CLI 同步

新增参数：

```text
--source-language / --source-lang
--target-language / --target-lang
--src-target-col
--gl-source-col
--gl-target-col
--aligned-target
```

`--bilingual` 继续可用，并作为 `--aligned-target` 的兼容别名。EN→DE 和 EN→FR 示例已写入中英文 README。

### 2.7 前端功能与界面同步

- 提取页第一步新增“源语言”和“目标语言”选择框。
- 切换目标语言后清除旧列识别状态，并重新映射同行目标列。
- 源文本列、同行译文列、术语表源列、术语表目标列、空术语表提示和运行摘要均使用当前语言名称。
- 源语言与目标语言相同时显示错误并禁用启动。
- 断点列表显示语言对；恢复任务时同步恢复语言、列映射和运行配置。
- 结果页根据结果中的语言字段动态显示源术语列和目标译文列。
- 新增“沿用同行译文”来源统计，并保留旧版“沿用原文英文”展示。
- 持久化配置中的非法语言对会回退为默认 `zh-Hans → en`，避免页面启动失败。
