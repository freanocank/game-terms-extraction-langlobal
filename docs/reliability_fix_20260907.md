## 原生交付与兼容边界

- `save_outputs` 仍只生成 `results.xlsx` 和原生命名的候选术语标注表。
- 工作表仍为“完整结果”和“术语表”；标注表 8 列顺序不变，默认“未审核”。
- 新来源证据属于完整结果的调试字段，不新增标注模板列或改变标注工具格式。
- 原生 UI/CLI 共享相同的提取、译文整理和导出入口；离线重放使用相同计票、证据处理和原生导出函数，不重跑 NER 或 AI 补译。
- 成功请求及完整三轮响应随断点保留。续跑输出目录可重新保存之前完成 chunk 的响应，用于完整离线回放。
- `source_span` / `target_span` 指向清理后的文本；`raw_source_span` / `raw_target_span` 指向原始文本。词位置是字符偏移，不是 token 索引。
- 旧断点缺少新摘要或来源证据时不会自动迁移。应使用新断点目录重新提取；已验证兼容的成功请求可按阶段复用。
